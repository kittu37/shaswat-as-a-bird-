# Shaswat's Snack Flight

A browser game with winged photo characters, randomized pipes and snack pickups, and angry enemies with horizontal flights, falling swoops, and angled charges.

## Play locally

Open `index.html` in a modern browser. No build step or package installation is needed. Google Fonts is optional; system fonts work offline.

- Space, Up Arrow, or tap: flap upward. Release to fall.
- P: pause or resume.
- Blue Lay's: 1 point.
- Red Lay's: 3 points and 2.25× scrolling speed for five seconds.
- Dodge the dotted enemy path during the 1.8-second warning.

## Files

- `index.html`: page and game controls.
- `style.css`: responsive layout.
- `game.js`: canvas drawing, physics, sound, scoring, and enemy behavior.
- `assets/`: supplied character and snack images.

## GitHub upload

Create an empty repository, then upload the contents of this folder at its root. Keep the `assets` folder alongside `index.html`. No Sites account or Sites configuration is required to run this copy.

The assets include supplied personal photos and third-party branding. Repository visibility determines who can download those files. No license is granted for those assets by this README.

The game runs entirely in the browser. Personal best is stored locally on the player's device.
